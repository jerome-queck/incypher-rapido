# H24 offline fixture contract

Status: frozen fixture protocol. Native results are recorded separately in
[`offline-h24-final-evidence-2026-09-20.md`](offline-h24-final-evidence-2026-09-20.md); historical
no-run statements below remain scoped to this fixture PR.

`rapido.offline_h24` defines the public, candidate-free H24 task catalogue and the private fixture
preparation boundary. The catalogue is fixed at 24 tasks: six easy sentinels, six medium artifact
tasks, six hard offline tasks, three AI-artifact tasks, and three synthetic-healthcare tasks. Their
per-arm caps are respectively 300, 600, 1,200, 600, and 600 seconds, totalling 16,200 seconds per
arm. Each public row declares its checker ID, artifact ceiling, CPU and memory ceiling,
compatibility, exposure policy, and prompt text.

Fixture preparation requires a caller-owned private seed of at least 32 bytes. Domain-separated
HMAC derivation makes task material and expected answers deterministic for one seed while keeping
the seed, answer, answer-derived digests, and private oracle state outside the public manifest and
receipt. The returned expected value is evaluator-only. Model workspaces receive only the bounded
artifact bundle and public task prompt. No task requires a network, target authority, executable
artifact, credential, prior candidate, solution, write-up, real patient record, or clinical advice.

All artifact paths are normalized relative paths. Absolute paths, traversal, links, duplicate
names, unsupported formats, excessive file counts, and size/resource-limit violations fail before
a native client can start. ZIP members receive the same path and size checks. Reference checkers
parse the generated bytes independently and never read caller paths or external state. AI and
healthcare records are wholly synthetic; instruction-like text inside an artifact is explicitly
untrusted data.

The public manifest freezes task structure and budgets, not experiment outcomes. Model descriptors,
arm order, the private order seed, gates, and the final benchmark source identity must be frozen in
the later H24 preregistration before any native result is unsealed. This fixture PR does not run the
official practice set and does not authorize live targets or production promotion.
